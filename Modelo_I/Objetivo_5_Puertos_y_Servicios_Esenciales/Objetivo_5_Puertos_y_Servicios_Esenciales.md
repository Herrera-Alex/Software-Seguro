# Objetivo 5: Puertos y servicios esenciales

## Servicios estándar por defecto

Los siguientes son los servicios estándar que se ejecutan por defecto en estos puertos fundamentales de red:

- **Puerto 20 (FTP - Data):** Se utiliza para la transferencia de datos en el protocolo FTP (Protocolo de Transferencia de Archivos) cuando opera en modo activo.
- **Puerto 21 (FTP - Control):** Se encarga de la autenticación y comandos de control en FTP; a través de él se establecen las conexiones iniciales antes de transferir archivos.
- **Puerto 22 (SSH / SFTP):** Aloja el servicio Secure Shell, utilizado para el acceso remoto seguro a servidores y la transferencia segura de archivos mediante SFTP.
- **Puerto 23 (Telnet):** Utilizado para el acceso remoto sin cifrar; actualmente está en desuso debido a que transmite las credenciales y datos en texto plano.
- **Puerto 25 (SMTP):** Es el puerto estándar para el envío y enrutamiento de correos electrónicos entre servidores (Simple Mail Transfer Protocol).
- **Puerto 53 (DNS):** Atiende las consultas del Sistema de Nombres de Dominio, encargándose de traducir nombres de dominio legibles (como ejemplo.com) en direcciones IP.
- **Puerto 80 (HTTP):** Soporta el tráfico de páginas web sin cifrar (Hypertext Transfer Protocol), sirviendo el contenido web básico.
- **Puerto 110 (POP3):** Utilizado por los clientes de correo para descargar mensajes desde el servidor (Post Office Protocol v3), habitualmente eliminándolos del servidor tras la descarga.
- **Puerto 443 (HTTPS):** Canaliza el tráfico web cifrado y seguro mediante protocolos SSL/TLS, protegiendo las transacciones y la navegación de los usuarios.
- **Puerto 3306 (MySQL):** Es el puerto por defecto para las conexiones y consultas a la base de datos relacional MySQL (y su bifurcación MariaDB).

## Resumen

Estos puertos representan servicios esenciales en redes y sistemas informáticos, ya que permiten funciones como acceso remoto seguro, transferencia de archivos, resolución de nombres, navegación web, correo electrónico y gestión de bases de datos.
